# Budget Assessment

Premium responsive budget assessment website.

## Included features
- Original expense list, amounts, and checked states preserved
- Editable starting budget, expense names, and amounts
- Live selected-expense total and remaining balance
- Select all, clear all, and add expense controls
- Independent Rent and EMI checkboxes
- Mobile-friendly layout and dark mode

## Run
Open `index.html` in a browser. No installation is needed.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload the files inside it (not the ZIP itself) to the root of your GitHub repository.
3. Commit the files.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.

This is a website package, not an Android APK or Android Studio project.
